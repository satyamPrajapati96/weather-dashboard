# 🌦️ Weather Dashboard

A responsive Weather Dashboard built using HTML, CSS, and JavaScript that displays real-time weather information for any city.

## ✨ Features

- 🔍 Search weather by city name
- 🌡️ Display current temperature and feels-like temperature
- 💧 Show humidity and wind speed
- 🌥️ Display weather conditions, pressure, cloud cover, and UV index
- 📅 Five-day weather forecast
- ⚡ Fetch API with async/await
- 🛡️ Error handling for invalid cities and network issues
- 📱 Responsive design for different screen sizes
- 🌐 Uses the Open-Meteo API — no API key required

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API
- Async/Await
- REST API (Open-Meteo)

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Enter a city name to view its weather.

## 📁 Project Structure

```text
weather-dashboard/
├── index.html
├── style.css
└── script.js
```

## 🌐 API

This project uses the free [Open-Meteo API](https://open-meteo.com/) for geocoding and weather forecast data.
